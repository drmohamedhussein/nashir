== Description ==

Nashir connects a WordPress site to your Nashir account. Schedule and publish from the cloud calendar or from wp-admin. This plugin is a connector only; it does not contain third-party product code.

== Installation ==

1. Upload the `nashir` folder to `/wp-content/plugins/`
2. Activate the plugin
3. Open Nashir in wp-admin, paste a pairing code from your Nashir account
